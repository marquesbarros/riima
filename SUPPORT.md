# Suporte e relato de problemas

O mantenedor é Lucas Marques Barros. Esta cópia não registra URL pública de
issues, endereço de e-mail de suporte ou remoto Git. Use o canal já estabelecido
para receber esta cópia e encaminhe o relato ao mantenedor. Se esse canal não
estiver disponível, preserve o relato localmente; este documento não cria
um serviço público ou endereço de contato verificável.

Para tornar o problema reproduzível, envie:

- versão de RIIMA, Python, sistema operacional e versões das dependências;
- comando ou passos mínimos, comportamento observado e resultado esperado;
- traceback completo, se houver, removendo nomes de usuário e caminhos privados;
- um exemplo sintético e, quando disponível, SHA-256 do artefato recebido;
- resultado de `python scripts/source_identity.py` para a cópia utilizada.

Não envie micrografias, projetos autocontidos ou arquivos de pesquisa sem
verificar consentimento e direitos. Para problemas de segurança, use o contato
privado já estabelecido com o mantenedor; a ausência de um canal privado público
permanece uma limitação operacional. Evite divulgar dados sensíveis em relatos.

[Instalação](docs/SHARING.md), [manual](docs/USER_GUIDE.md) e
[contribuições](CONTRIBUTING.md) contêm os procedimentos disponíveis. O suporte
é prestado conforme disponibilidade, sem garantia de prazo.
